# 错题本

手机上用的拍照错题本。纯静态页面：HTML、CSS、一份共享的 `app.js`，没有框架，也不用构建。数据在 Supabase 里，按账号分开。

## 现在有哪些页面

- `index.html` 登录。账号加密码，邮箱可填可不填。登录一次会保持，主动退出才要重填。
- `home.html` 主页。拍照、练习、错题库、知识点、笔记本都从这里进。
- `upload.html` 拍照或从相册选题，框出题目后识别。认不出来可以手改题干和选项再保存。空题干存不了。
- `bank.html` 错题库。按学科看，可以改学科、改解析、删除、清理重复。
- `practice.html` / `practice-run.html` 从未掌握的题里抽着练。有选项就点选项；没有选项（判断题、主观题）用「我会了 / 不会」自己打分，连续三次「我会了」会标成已经会了。
- `knowledge.html` 收藏的知识点。星标存在云端，换设备登录同一个账号能看到。
- `notebook.html` 自己的笔记，跟错题分开。按账号存在云端，图片进存储桶。
- `stats.html` 按北京时间统计。
- `admin.html` 只有管理员能看登录记录和用量，看不到别人的题目。

打开方式：在这个目录运行 `python3 -m http.server`，用手机或浏览器访问。不要直接双击 HTML 文件，否则登录脚本可能被浏览器拦住。

## 你需要在 Supabase 里跑一次的 SQL

网站在没跑下面这条 SQL 之前也能开：笔记会先写进原来的 `notebook_items.content`，收藏先留在这台手机上，插图片会提示还没建存储桶。跑完再刷新，就按新结构存。

1. 打开 Supabase 后台 → SQL Editor → New query。
2. 把 `supabase/migrations/2026-11-03-notes-favorites-images.sql` 里的内容全部贴进去，点 Run。只跑一次，重复跑不会清掉已有笔记。
3. 这条 SQL 会做三件事：
   - 给笔记本表加上标题、正文、富文本和图片路径，旧的 `content` / `color` 行还在，新笔记页会把它们显示出来。
   - 新建 `knowledge_favorites`，每个人只能读写自己的收藏。
   - 新建私有存储桶 `note-images`，图片放在自己的用户 id 目录下，别人读不到。

以前如果在「token 用量」里还没建表，管理页那一块仍要另跑 `supabase/token_usage.sql`，这个文件不管那张表。

## 笔记怎么从旧数据里过来

- 这台手机浏览器里 `localStorage` 的 `notes_v1`，会在这个账号第一次打开网站时合并进云端。合并成功后，本机那份大图会清掉，避免把浏览器空间撑满。传不上去的会留在本机，页面上仍看得到，并给出红色提示。
- 云端原来的 `notebook_items`（只有一段文字和黑/红/蓝）会直接出现在新的笔记列表里。
- 保存失败不再悄悄丢掉，屏幕上方会出红字。

## 配置

`config.js` 里是 Supabase 地址和 anon key，以及管理员账号。不要把 service_role key 写进前端。页面上不会显示管理员账号名。
